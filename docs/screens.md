## 1. 画面一覧

### 🌐 公開ページ（誰でも閲覧可能）
1. **トップページ (`/`)**: ポートフォリオの顔となるエントランス。
2. **プロフィール (`/profile`)**: 経歴や自己紹介の動的表示。
3. **実績 (`/works`)**: データベースから取得した実績一覧のカード型UI表示。
4. **スキル (`/skills`)**: 習得スキルのレーティングまたは一覧表示。
5. **コンタクト (`/contact`)**: 問い合わせ送信フォーム。

### 🔒 管理画面（要ログイン・Admin権限）
6. **管理者ダッシュボード (`/admin`)**: コンテンツ管理の拠点。
7. **実績登録・編集フォーム (`/admin/edit`)**: 各種文言や実績テキストのCRUD操作、および実績に紐づく画像のバイナリ/Base64送信UI（アップローダーコンポーネント内包）。

---

## 2. UIの役割と入力項目

### 問い合わせフォーム (`/contact`)
- **役割**: ユーザーからのメッセージを受け付け、バックエンド経由でDB保存およびSlack通知を行う。
- **入力項目**:
  * お名前 (`senderName`): テキスト入力、必須
  * メールアドレス (`senderEmail`): メール形式、必須
  * 本文 (`messageContent`): テキストエリア、必須

### 実績登録・更新フォーム (`/admin/edit`)
- **役割**: 管理者が実績コンテンツを更新する。
- **入力項目**:
  * 実績名 (`achievementTitle`): テキスト入力、必須
  * 説明文 (`description`): テキストエリア、必須
  * 画像 (`imageData`): ファイルアップローダー（Base64文字列またはBlobへの変換処理をフロント側で実施）

---

## 3. 状態管理・ルーティング保護概要
- **ルーティング保護**: フロントエンドの **`front/src/middleware.ts`** または LayoutレベルでFirebase Authのセッションをチェック。未認証時はリダイレクトせず、**404ページ（NotFoundコンポーネント）** をダイレクトに描画して管理画面の存在自体を隠蔽します。
- **フロントエンド状態管理**: 基本的に Server Components によるデータ取得を主軸とし、フォームの入力値制御など局所的な状態管理には React の `useState` などの最小限のHooksを利用（複雑なグローバルストアはMVPフェーズでは導入しない）。
